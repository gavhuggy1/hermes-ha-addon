# Hermes Agent HA Add-on

Home Assistant add-on for Hermes Agent.

## Installation

1. Settings -> Add-ons -> Add-on Store
2. Menu -> Repositories -> Add: https://github.com/gavhuggy1/hermes-ha-addon
3. Install -> Start

## First Use

On first start, a terminal opens. Run `hermes setup`.

## Voice

Install HA add-ons: Whisper, Piper, openWakeWord.
